# Вкусфера / Vkusfera (репозиторий Rezeptwold)

Android-приложение кулинарной энциклопедии мира: автономная база рецептов, пользовательские рецепты и онлайн-обновления.

Минимальная версия Android: 5.0 (API 21), приложение без нативных библиотек, встраиваемая офлайн-библиотека.

## Сборка APK

Откройте GitHub Actions → Build Android APK → артефакт `RezeptWorld-debug-apk`.

## Каталог

Текущая офлайн-версия: **539 карточек**, из них **529 рецептов с количествами ингредиентов** и **10 справочных материалов**. После версии v0.4 добавлено **102 новых**: 28 рецептов выпечки, 34 основных блюда, 20 напитков и 20 холодильных маринадов, а также 15 подробных журнальных рецептов. Ни одна карточка не дублирует другую по названию.

В национальных блюдах встречаются домашние адаптации; это отмечено в данных, они не подменяют подтверждённые аутентичные рецептуры. Рецепты холодильных маринадов не предназначены для герметичной консервации и хранения без холодильника.

Проверка базы выполняется автоматически перед сборкой командой `python3 tools/validate_catalog.py`.

## Режимы

- Офлайн: рецепты встроены в приложение, работает без сети, пользовательские рецепты хранятся локально.
- Онлайн: загрузка дополнительных карточек из `recipes/updates.json` (с проверкой структуры) через HTTPS.

Выпечка, кухни мира, напитки, ферментация и заготовки; проект постепенно пополняется, целевой размер библиотеки — 20 000 проверяемых записей.

Рецепты алкогольных напитков предназначены только для совершеннолетних с учётом местного законодательства. Домашняя дистилляция может быть опасной и регулироваться законом; придерживайтесь пищевой безопасности при хранении и консервировании.

## Новое в 0.6.0

Выбор страны и её рецептов на главной, отдельные меню алкоголя, фотографии блюд для редакционных карточек и тематические изображения остальных, пошаговые иллюстрации действий (`steps/*.svg`) у всех рецептов. Схемы этапов не являются фотографиями конкретного процесса. Фотографии готовых блюд взяты по лицензии Unsplash, авторы указаны в карточках.

## Новое в 0.7.0: обложки всех карточек

Все 539 рецептов и справочных карточек теперь имеют **своё отличающееся офлайн-изображение**: рисунок композиционно зависит от типа блюда, названия и ингредиентов. Это автоматически создаваемые **иллюстрации**, а не фотографии реально приготовленной порции. Четыре фотографии, подобранные к отдельным блюдам, показываются поверх иллюстрированной резервной обложки. Если фотография недоступна, показывается рисунок. Новые рисунки не требуют интернет-доступа, они создаются по необходимости, 72 последних хранятся в оперативном кэше. Кулинарные фото шагов для каждого блюда пока не добавлены; иллюстрации этапов общего типа (`steps/*.svg`) сохраняются. Тест `node tools/validate_art.js` убеждается, что все 539 картинок корректны и различаются.

## v0.8.0 — Поиск в Google

Два способа искать рецепты:

1. **Офлайн**: поиск по уже встроенной базе (539 карточек) и своим рецептам; интернет не нужен.
2. **Онлайн / Google**: после переключения в режим «Онлайн» пользователь вводит блюдо или ингредиенты и нажимает «Найти в Google». Android открывает полноценный Google Search в установленном внешнем браузере (например, Chrome), корректно кодируя запрос UTF-8. Это позволяет искать блюда и рецепты, которых нет в офлайн-каталоге, без API-ключей. **Результаты Google пока не отображаются внутри самого приложения и не импортируются автоматически**. Ссылку, найденную в браузере, можно использовать как источник, переписав рецепт в «Мои рецепты» через «＋ Добавить рецепт вручную».

Поиск Google запускается **только по нажатию пользователя или Enter в онлайн-режиме**, а не при каждом вводимом символе. Переключение режима больше не запускает автоматически обновления. «Обновить» по-прежнему скачивает дополнительные записи из GitHub как отдельную операцию. Запрос передаётся Google, что предполагает подключение к сети и политику конфиденциальности Google. На Android старше 5.0 совместимость не заявляется.

Почему не встроены выдача Google и фотографии? Существовавший JSON API Google Custom Search закрыт для новых пользователей, а без отдельного сервиса/API незаконно и ненадёжно выдавать веб-страницы Google за прямой API. План будущего улучшения — официальный поисковый сервис с серверной конфигурацией и импорт рецептов с сохранением источника после проверки.

## v0.9.0 — настоящие фотографии готовых блюд

В пошаговом приготовлении остаются прежние 7 типов схематичных иллюстраций действий. Фотографии на обложках и в начале рецептов теперь берутся **только из вручную проверенного каталога** `app/src/main/assets/photo-catalog.js`: названия реальных блюд, оригиналы Wikimedia Commons, авторы и лицензии. Для первого пакета вручную отобрано 15 изображений для 18 карточек; фактическое число включённых в APK зависит от успешной загрузки и отображается в журнале сборки. Ранее применявшиеся неподтверждённые тематические картинки удалены из четырёх редакционных рецептов.

Все скачанные фотографии оптимизируются для работы офлайн: 700×540 пикселей максимум, WebP, качество 74. Проверка источника, длины, лицензии, размера и пригодности файла выполняется в CI. Только файлы, **действительно попавшие в APK**, получают подпись «Фотография блюда». Для остальных карточек временно остаётся рисунок, честно обозначенный «Иллюстрация», пока их фотография не будет проверена. Рецепты и ингредиенты не менялись; целевой каталог остаётся 20 000.

Фото из источников могут изображать типичный образец блюда, а не буквальный результат приготовления по количествам ингредиентов в конкретной карточке. Атрибуция и условия лицензии отображаются в карточке; изображения с лицензиями Creative Commons Attribution-ShareAlike сохраняют требования оригинальной лицензии.

## v0.9.1 — исправление пропавших рецептов в меню

Проверено: офлайн APK содержит ровно **539 записей** (529 рецептов и 10 справочных статей), ни одна не удалена. Прежнее приложение показывало 3–12 блюд в некоторых фильтрах из-за фрагментации на маленькие категории (свыше 80 значений), дополнительного невидимого пересечения фильтра с вкладкой и неверной классификации «безалкогольных напитков» как алкоголя.

Исправления:
- первая плитка «Все рецепты» открывает полную библиотеку;
- в каталоге постоянно видна кнопка «Открыть всю книгу»;
- списки «Категории» теперь широкие понятные группы (выпечка, десерты, супы, алкоголь и т. д.), а не десятки категорий по 1–4 карточки;
- переключение вкладки очищает конфликтующую выбранную категорию, и наоборот;
- чётко написано «Показано 24 из N», а кнопка «Показать ещё 24» сообщает остаток;
- национальные кухни в вариантах «Италия — домашняя адаптация» учитываются вместе с Италией;
- исправлена ошибка, отправлявшая безалкогольные напитки в алкоголь;
- регрессионный тест `node tools/validate_catalog_groups.js` проверяет общую библиотеку и количество карточек в больших разделах.

Числа для базовой v0.9.1: все 539, выпечка 149, десерты 55, супы 24, основные блюда 117, безалкогольные напитки 45, алкоголь 131, коктейли 52. Эти крупные разделы могут пересекаться: например, пирожное относится и к выпечке, и к десертам. Отдельные маленькие разделы (рыба 6, некоторые страны) действительно ещё требуют новых рецептов, а не настройки отображения.
