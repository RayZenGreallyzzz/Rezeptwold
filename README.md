# Вкусфера / Vkusfera (репозиторий Rezeptwold)

Android-приложение кулинарной энциклопедии мира: автономная база рецептов, пользовательские рецепты и онлайн-обновления.

Минимальная версия Android: 5.0 (API 21), приложение без нативных библиотек, встраиваемая офлайн-библиотека.

## Сборка APK

Откройте GitHub Actions → Build Android APK → артефакт `RezeptWorld-debug-apk`.

## Каталог

Текущая офлайн-версия: **524 карточки**, из них **514 рецептов с количествами ингредиентов** и **10 справочных материалов**. После версии v0.4 добавлено **102 новых**: 28 рецептов выпечки, 34 основных блюда, 20 напитков и 20 холодильных маринадов. Ни одна карточка не дублирует другую по названию.

В национальных блюдах встречаются домашние адаптации; это отмечено в данных, они не подменяют подтверждённые аутентичные рецептуры. Рецепты холодильных маринадов не предназначены для герметичной консервации и хранения без холодильника.

Проверка базы выполняется автоматически перед сборкой командой `python3 tools/validate_catalog.py`.

## Режимы

- Офлайн: рецепты встроены в приложение, работает без сети, пользовательские рецепты хранятся локально.
- Онлайн: загрузка дополнительных карточек из `recipes/updates.json` (с проверкой структуры) через HTTPS.

Выпечка, кухни мира, напитки, ферментация и заготовки; проект постепенно пополняется, целевой размер библиотеки — 20 000 проверяемых записей.

Рецепты алкогольных напитков предназначены только для совершеннолетних с учётом местного законодательства. Домашняя дистилляция может быть опасной и регулироваться законом; придерживайтесь пищевой безопасности при хранении и консервировании.
